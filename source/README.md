# На одной дорожке — v15

В v15 добавлены тонкие светлые рамки вокруг фотографий, сохранены арка, размеры и мобильный вертикальный фотоальбом. Сборка проверена; визуальная проверка недоступна из-за отсутствующего предпросмотра. Подключение Google Таблиц пользователь завершает самостоятельно.

Михаил и Елизавета · 05.01.2027 · Новосибирск.

Откройте «Открыть-приглашение.html» из архива. Всё необходимое для просмотра встроено, установка не нужна.

Выполнены правки десяти разделов: новый первый экран, обращение к гостям, таймер дни/часы/минуты до сбора гостей 05.01.2027 в 15:00 по Новосибирску; широкие фотографии; красный пунктирный маршрут программы 15:00/16:00/22:00; Парк-отель Slumo, Veranda, Новая Заря 53а и ссылка 2ГИС; обновлённая палитра и пожелания; контакт ведущего пока отмечен заполнителем.

Анкета: срок до 12 декабря, основной гость и попутчики, проверка обязательных полей, отказ скрывает следующие вопросы, ребёнку вместо напитков нужен возраст. Можно добавлять/удалять гостей без искусственного лимита. Обязательные поля проверяются перед добавлением следующего гостя и отправкой.

ВАЖНО: сохранение в Google Таблицы пока не подключено. Форма прямо сообщает об этом. Подготовлены integration/Code.gs и integration/Подключение.txt. Для включения необходимы ваша таблица, развёртывание Apps Script и адрес /exec в src/rsvp-config.js. До отправки приглашений проведите реальный тест: взрослый, ребёнок, отказ, повторная отправка. Каждому гостю соответствует отдельная строка, ID связывает семейную анкету.

Исходники — source. Для разработки npm install и npm run dev; сборка npm run build; автономный файл python3 scripts/export-offline.py. Проверки анкеты node --test tests/rsvp.test.mjs.

Восемь автоматических проверок и сборка прошли. Визуальная проверка и проверка браузерных взаимодействий заблокированы недоступностью встроенного предпросмотра; настоящая запись в таблицу требует подключения и проверки.
